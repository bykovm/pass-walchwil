Получение гражданства в Швейцарии представляет собой многоступенчатый процесс, который проходит на трёх уровнях управления [2]. 

<Steps>

1. **Уровень общины (Gemeinde)**
Присвоение муниципального гражданства (*Gemeindebürgerrecht*). Решение принимает гражданская община (*Bürgergemeinde*).

2. **Уровень кантона (Kanton)**
Присвоение кантонального гражданства (*Kantonsbürgerrecht*). Решение принимает правительство кантона (*Regierungsrat*).

3. **Федеральный уровень (Bund)**
Получение разрешения на натурализацию (*Einbürgerungsbewilligung*). Решение принимает Государственный секретариат по миграции (*Staatssekretariat für Migration, SEM*).

</Steps>

Присвоение гражданства на каждом уровне происходит последовательно, и только после прохождения всех трёх этапов процесс считается завершенным [2].
