- **Walchwil** — история, география, политика, легенды
- **Справочник** — глоссарий немецких терминов, официальные ссылки

## Как пользоваться

1. Изучайте разделы по темам
2. Запоминайте официальные термины на немецком
3. Проверяйте актуальность данных по официальным источникам
